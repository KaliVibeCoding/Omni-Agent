# Glossary

> Terms, acronyms, product names, and internal concepts you'll encounter in this codebase.

---

## A

**A2P 10DLC** — Application-to-Person 10-Digit Long Code. US compliance regime for business SMS over standard phone numbers. Required Twilio registration for high-volume SMS.

**ADR** — Architecture Decision Record. A short doc capturing one architectural choice (see [`../architecture/ADRs.md`](../architecture/ADRs.md)).

**AES-256-GCM** — Authenticated symmetric encryption. We use it via Web Crypto API in the Worker to protect tenant Twilio credentials at rest in D1.

**AGI Framework** — Our multi-agent pipeline builder. Lets users compose intent → extract → decide → compose → notify nodes. Business+ plan only.

**Allowlist (master admin)** — Hardcoded set of emails granted master admin privileges. Source: `MASTER_ADMIN_EMAILS` env var + `src/lib/admin.ts` constant on both Worker and frontend.

**Anthropic** — Provider of the Claude family of LLMs. Default model: `claude-3-5-sonnet`.

**API client (generated)** — TypeScript React Query hooks generated by Orval from our OpenAPI spec. Lives at `lib/api-client-react/`.

**apiFetch** — Hand-rolled fetch helper in `src/lib/api.ts` (frontend) that auto-injects `Authorization: Bearer <Clerk JWT>` and parses JSON into `ApiHttpError` on failures.

**App.tsx** — Frontend root. Hosts `ClerkProvider`, `ApiAuthBridge`, `QueryClientProvider`, and the wouter `Router`.

## B

**Bearer token** — Auth scheme where the client sends `Authorization: Bearer <token>`. We use this with Clerk session JWTs.

**Bindings (Cloudflare)** — Resources attached to a Worker via `wrangler.toml`: D1 databases, KV namespaces, R2 buckets, Durable Objects. Available on the `env` object at runtime.

## C

**Clerk** — Authentication provider. Issues RS256 JWTs we verify via JWKS. Also provides backend API for email lookup used in master admin gating.

**CLōD** — A Claude-compatible API provider (optional fallback).

**Composio** — Automation platform (optional integration for AGI node connectors).

**Compatibility date** — Cloudflare Workers config field controlling which platform features are enabled. Updated cautiously.

## D

**D1** — Cloudflare's managed serverless SQLite. Our production database.

**DisputeFox** — Credit-repair vendor API integration.

**Drizzle** — TypeScript ORM with schema-first design. Used for both D1 (Worker) and Postgres (dev API).

**Durable Object** — Cloudflare primitive for strongly-consistent stateful objects. Reserved for rate-limiting / coordination if/when needed.

## E

**E.164** — International phone number format: `+<country><number>`, no spaces or punctuation. Example: `+15555550123`.

**ENCRYPTION_KEY** — Base64-encoded 32-byte secret used by `lib/encrypt.ts` to AES-256-GCM encrypt/decrypt tenant credentials.

**Enterprise plan** — Top tier. Custom pricing. Master admins are always reported as enterprise regardless of subscription state.

## F

**Free / Starter / Growth / Business / Enterprise** — Subscription tiers. Prices: $0 / $79 / $199 / $499 / custom.

## G

**Generated hooks** — React Query hooks produced by `pnpm run codegen` from the OpenAPI spec. Authenticated automatically via `setAuthTokenGetter`.

## H

**Hono** — Lightweight web framework optimized for Workers. Our Worker is a Hono app.

**HSM / KMS** — Hardware/Cloud-based key management. Not yet used; `ENCRYPTION_KEY` is stored as a plain Worker secret.

## J

**JWKS** — JSON Web Key Set. Public keys Clerk publishes to verify JWT signatures. Worker fetches and caches these.

**JWT** — JSON Web Token. Clerk issues these as session tokens; we validate the RS256 signature.

## K

**KV (Cloudflare)** — Eventually-consistent key-value store. Optional for caching.

## L

**Lock-in** — A risk we accept by choosing Cloudflare Workers + D1 (see [`ADRs.md`](../architecture/ADRs.md#adr-001)).

## M

**Master admin** — A user whose Clerk email is in the allowlist. Has access to `/admin`, all admin APIs, can read/modify any tenant, and bypasses plan gating.

**MFSN** — "MyFreeScoreNow" — credit-repair integration.

**Miniflare** — Local-first Workers runtime used by `wrangler dev` and tests.

**Monorepo** — Single repo containing many packages, managed with pnpm workspaces.

**Multitenancy** — Multiple isolated customer accounts share the same infrastructure but never each other's data. See [`MULTITENANCY.md`](../architecture/MULTITENANCY.md).

## N

**niche_records** — Generic D1 table backing all 19 industry hubs. Polymorphic JSON `data` column.

**NFR** — Non-Functional Requirement. Latency, availability, security targets.

## O

**OpenAPI** — Spec format for HTTP APIs. We treat the spec as source of truth; codegen produces both server types and client hooks.

**OpenRouter** — Multi-model gateway (alternative to direct provider keys).

**Orval** — OpenAPI → TypeScript code generator.

## P

**Pages (Cloudflare)** — Static site + serverless functions hosting. We deploy the two React apps to Pages.

**Pages Function** — Per-route serverless function colocated with a Pages project. Our `functions/api/[[path]].ts` proxies `/api/*` to the Worker.

**pnpm workspaces** — Monorepo package manager. Hoists shared deps, links workspace packages by name.

**Plan gating** — Returning HTTP 402 when a request requires a higher plan than the caller has.

**ProtectedRoute** — Frontend route guard component that redirects unauthenticated (or non-admin for admin routes) users.

## Q

**Query client (TanStack)** — Wrapper around server state. We use it for all authenticated API calls.

## R

**R2** — Cloudflare's S3-compatible object storage. Optional for media uploads and DB backups.

**RA Compliance** — Regulatory adherence; varies per niche (TCPA for SMS, HIPAA for medical, FERPA for education, etc.). See `NICHE_PLAYBOOKS.md`.

**React Query** — See "Query client".

**Resend** — Transactional email provider.

**RPO / RTO** — Recovery Point Objective / Recovery Time Objective. Disaster recovery targets. See `BACKUP_RESTORE.md`.

## S

**SDK (Clerk Backend)** — `@clerk/backend` — used in the Worker to look up user emails for admin gating.

**setAuthTokenGetter** — Function exported from `lib/api-client-react/src/custom-fetch.ts`. Wires the Clerk `getToken` function into the generated hooks so every request carries a Bearer token.

**SEV-1..SEV-4** — Incident severity levels. See `INCIDENT_RESPONSE.md`.

**SSE** — Server-Sent Events. Used by `/api/chat` to stream LLM responses.

**Stripe Customer Portal** — Hosted page where customers manage subscriptions.

**STRIDE** — Threat modeling framework: Spoofing, Tampering, Repudiation, Information disclosure, Denial of service, Elevation of privilege.

## T

**TanStack Query** — React Query, server-state library. Same thing.

**TCPA** — US Telephone Consumer Protection Act. Governs commercial SMS/calls. Requires consent + opt-out.

**Tenant** — A customer organization. Currently 1 user = 1 tenant; team support is roadmap.

**tenant_credentials** — D1 table storing per-tenant encrypted Twilio creds + plan.

**Twilio** — SMS / Voice / Video provider. Per-tenant credentials (not platform-shared).

**TwiML** — Twilio Markup Language. XML returned to Twilio to control call flow.

## U

**useApi** — Frontend hook combining apiFetch with React Query.

**useMasterAdmin** — Frontend hook that returns `true` if `/api/me` reports `isMasterAdmin: true`.

**useMe** — Frontend hook returning current user identity + entitlements.

## V

**Vite** — Frontend build tool. Used by both `twilio-platform` and `twilio-omni-agent`.

## W

**Webhook** — Inbound HTTP call from a third party (Stripe, Twilio). Signature-validated before processing.

**Web Crypto API** — Built-in browser/Worker API for cryptography. Used by `lib/encrypt.ts`.

**Worker (Cloudflare)** — Edge-runtime serverless function. Our entire production API is one Worker.

**Workspace** — pnpm logical unit. Each package under `artifacts/` and `lib/` is a workspace member.

**wouter** — Tiny React router used in the frontend (not React Router).

**wrangler** — Cloudflare's CLI. Used for deploys, secrets, D1, logs.

## Z

**Zod** — TypeScript-first schema validation. Used for runtime input checking on Worker routes.
